# 客服退貨處理作業流程（SOP）

適用人員：客服專員、客服主管
適用通路：蝦皮商城、LINE 官方帳號、官網客服信箱

## 1. 接收客戶退貨訊息
客服每天 9:00、13:00、17:00 檢查蝦皮聊聊、LINE 與客服信箱。收到退貨訊息後，須在 4 小時內（工作時間）第一次回覆客戶。請客戶提供：訂單編號、購買商品、想退貨的原因，若是商品異常再請附上照片或影片。資料不齊全時，先用「補件範本」請客戶補充，補件期間案件狀態標為「待補件」。

## 2. 查詢訂單資料
到蝦皮賣家中心以訂單編號查詢：下單日期、付款方式、出貨日期與物流狀態。黑貓宅急便的配達日期可在物流追蹤頁面確認，鑑賞期以配達日的隔天起算。查無訂單、或客戶描述的商品與訂單不一致時，不要自行猜測，轉交主管處理。

## 3. 確認是否符合退貨條件
對照《退貨與退款政策》確認：是否在七天鑑賞期內、商品狀態是否完整、是否屬於不受理退貨的品項。符合條件者回覆客戶退貨寄回方式；不符合條件時，向客戶說明原因並提供保固維修選項。客戶反映過熱、冒煙等安全問題，或表示要申訴時，一律轉交主管，不要自行判斷。

## 4. 轉交主管
在 LINE 客服群組標記客服主管，附上訂單編號、客戶描述、商品照片與已查到的訂單資訊。主管需在 24 小時內回覆處理指示；安全問題由主管直接打電話給客戶。

## 5. 回覆客戶與結案
回覆內容須包含：處理結果、退貨寄回地址或維修方式、預計退款時間。使用客服回覆範本，語氣保持禮貌，不要承諾政策以外的補償。完成後在客服紀錄表填寫結案日期與處理結果。
