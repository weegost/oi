# 小名 3C 網店 退貨與退款政策

## 一、七天鑑賞期
依消費者保護法，網路購物享有七天猶豫期（鑑賞期），自客戶收到商品的隔天起算七天。鑑賞期內客戶可無理由申請退貨，運費由本店負擔。超過七天的退貨申請，原則上不受理，除非屬於商品瑕疵或保固範圍。

## 二、可退貨的商品狀態
商品須保持完整：主機、配件、說明書、保固卡與原廠外盒都要齊全。僅拆封試用、外觀無刮傷與使用痕跡者可全額退款。外盒嚴重破損、配件缺漏或有明顯使用痕跡者，依缺損程度酌收整新費，最高不超過售價 20%。耳機、行動電源等已拆封的個人衛生用品，若無瑕疵不受理退貨。

## 三、商品瑕疵與保固
收到商品七天內發現功能異常，視為到貨瑕疵，可選擇換新品或全額退款。超過七天但在一年保固內，提供免費維修，不辦理退款。需請客戶提供訂單編號、商品照片或影片說明異常狀況。

## 四、疑似商品安全問題
客戶反映商品過熱、冒煙、異味、膨脹或觸電等情形，一律視為疑似安全問題：
1. 客服立即請客戶停止使用並拔除電源，不要自行拆解。
2. 不論是否在鑑賞期內，都必須轉交客服主管處理，客服不得自行承諾退款或賠償。
3. 主管需在 24 小時內以電話聯繫客戶，必要時請客戶寄回商品送檢。
4. 主管應查詢經濟部標準檢驗局是否有同類商品的處分或召回資訊。

## 五、退款方式與時程
退貨商品寄回並檢查無誤後，3 個工作天內辦理退款。信用卡付款退回原卡，入帳時間依發卡銀行約 7 至 14 天；超商取貨付款與 ATM 轉帳由客戶提供帳戶，以匯款方式退款。退款金額超過新台幣 5,000 元，須由客服主管核准後才能執行。

## 六、爭議處理
客戶對處理結果不滿意、表示要向消保官申訴或在評價留下負評時，客服應轉交主管，不得自行與客戶爭論。主管需記錄爭議內容與處理過程，保存至少一年。
